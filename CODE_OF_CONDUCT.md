# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and constructive environment for everyone who participates in this project.

Contributors, students, developers, maintainers, and community members are expected to interact professionally and respectfully.

## Expected Behavior

Examples of positive behavior include:

- Being respectful and considerate toward others.
- Providing constructive feedback.
- Welcoming different perspectives and experiences.
- Asking questions in a respectful manner.
- Helping others learn and improve.
- Focusing discussions on technical and educational goals.
- Accepting constructive criticism gracefully.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment, discrimination, or personal attacks.
- Trolling or deliberately disruptive behavior.
- Insulting or degrading comments.
- Publishing someone's private information without permission.
- Intentionally misleading or malicious contributions.
- Threats or other inappropriate behavior.
- Any conduct that creates an unsafe or hostile environment.

## Technical Discussions

Technical disagreements are normal and encouraged when handled constructively.

Focus discussions on:

- Code correctness
- Performance
- Maintainability
- CUDA best practices
- Documentation
- Educational value

Critique ideas and implementations rather than individuals.

## Reporting Problems

If you experience or observe unacceptable behavior, report it to the project maintainers through the appropriate GitHub communication channel.

When reporting an issue, provide relevant details and avoid sharing private or sensitive information publicly.

## Maintainer Responsibilities

Project maintainers are responsible for helping maintain a respectful community environment.

Maintainers may take appropriate action when behavior violates this Code of Conduct, including removing inappropriate content or restricting participation when necessary.

## Scope

This Code of Conduct applies to project spaces, issues, pull requests, discussions, and other community interactions related to this repository.

## Enforcement

Violations may be reviewed by project maintainers.

Actions taken will depend on the severity and circumstances of the violation.

## License

This Code of Conduct is provided for the benefit of the project community and does not modify the project's software license.

## Final Note

We want this repository to remain a place where people can build, contribute, ask questions, and learn CUDA together.

Thank you for helping maintain a respectful and constructive community.
